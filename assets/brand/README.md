# Proposed identity: Garden passage

An original vector emblem combines an arched garden entrance with a gently winding path. A serif “Kelly Francis” wordmark and spaced “DESIGN” line keep the identity quiet beside detailed photography.

This is an optional concept for client review. It has not been approved by Kelly and does not represent an existing registered identity.

Logo artwork is transparent, outlined SVG. It contains no external image or font requests. The presentation board includes its own solid backgrounds. The source SVGs remain editable in vector software; lettering is paths rather than live text.

## Usage

- Use the full horizontal logo at about 240 to 260px on desktop and the compact logo at about 175 to 185px on phones. Inspect the descriptor at the actual rendered size. Use the text business name as the accessible label.
- At very small sizes, use the simplified favicon instead of the complete wordmark.
- Leave clear space of at least half the emblem width around a standalone logo. The website header can use a compact alignment if the neighboring controls remain distinct.
- Preserve the original aspect ratio. No skewing, shadows, recoloring individual letters, or placing forest artwork over busy dark photographs.
- Use the reversed variant on the forest footer. The board is for design review and should not ship as a website background or hero.
- Check favicon readability at 16 and 32px and export a PNG/ICO fallback during the website build if the selected browser/host setup needs one.

## Provenance

The arch/path geometry, arrangement, palette, and layout were created for this brief. Wordmark lettering was converted to vector outlines from Latin Modern Roman 10 Regular; the descriptor uses Latin Modern Sans 10 Regular. Latin Modern is credited to Bogusław Jackowski and Janusz M. Nowacki, based on Donald E. Knuth's Computer Modern, and distributed under the GUST Font License. No font binaries are included here.

The website's recommended Cormorant Garamond and Manrope web fonts are separate future implementation assets. Their licensing and files must be obtained at that stage. These SVGs do not require either web font to display.
