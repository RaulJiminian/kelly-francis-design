# Snowbird brand assets

The established Snowbird logo uses an olive `snowbird` wordmark, a blue bird, and the descriptor `LANDSCAPE + INTERIORS`.

## Files

| File | Use |
| --- | --- |
| `source/snowbird-logo-original.png` | Untouched 555 × 175 logo downloaded from Snowbird's prior public site at the client's direction |
| `snowbird-logo.png` | Transparent, tightly trimmed website logo generated from the supplied original |
| `public/assets/brand/snowbird-bird.png` | Browser icon derived from the blue bird in the supplied logo |
| `public/og.jpg` | 1200 × 630 social card combining the supplied logo with Snowbird project photography |

Run `npm run brand:prepare` to rebuild the derived files. The script removes the original white matte without redrawing or changing the logo lettering. Keep the logo's aspect ratio and do not place the full-color artwork directly on a busy photograph.
