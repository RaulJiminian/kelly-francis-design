# Snowbird Landscape

Working website preview • September 7, 2026

A photography-led portfolio for Snowbird Landscape, designed to feel like a beautifully edited garden journal. Large finished-project photographs, warm ivory, expressive serif typography, and Snowbird's olive-and-blue logo establish the visual identity. Visitors can explore six transformations, browse a dedicated project collage, learn about the practice, and make contact.

**A complete React preview is implemented.** The six project names, public descriptions, logo, and 26 after photographs come from Snowbird's prior website. Nine matched before photographs come from `assets/updatedBefore/`; Shady Planters intentionally shows a neutral placeholder because no before photo was supplied. `assets/raw/` and `assets/starter/` remain unreferenced. New Vision, Transformation, and detail copy remains visibly marked as working copy until client review.

## Start here

1. Use Node 22.12 or newer and run `npm install`.
2. Run `npm run dev`, then open the local URL Vite prints.
3. Run `npm run build` for a production preview. The build validates content and prepares responsive photo derivatives first.
4. Run `npm run test:smoke` for the bounded mobile/desktop browser checks.
5. Follow [MAINTENANCE.md](MAINTENANCE.md) when approved copy, contact details, or replacement photos arrive.

## Netlify preview

The repository includes `netlify.toml`; Netlify should use the repository root, `npm run build`, and the generated `dist/` publish directory. The normal build intentionally creates responsive derivatives from the tracked authoring photos. Generated files remain out of Git, and the optimized clean-image pass is designed to complete without depending on a warm Netlify cache. Direct visits to `/collage` and `/work/:slug` use the configured SPA fallback.

## Brand assets

The site uses Snowbird's established `snowbird` wordmark and `LANDSCAPE + INTERIORS` descriptor. The archived white matte was removed without redrawing the artwork, and a bird favicon plus refreshed social preview are generated by `npm run brand:prepare`.

No stock or AI-generated landscaping photographs are used. Website imagery comes from Snowbird's prior site and the client-supplied updated-before set, then becomes metadata-free responsive derivatives at build time.

## Remaining client inputs

- A before photograph for Shady Planters, if one exists.
- Approval or revisions for the new Vision, Transformation, About, and image-detail copy.
- Photographer credits and a final privacy/rights check for every photograph.
- A verified inquiry email if email should be offered alongside the confirmed phone and Instagram links.

The current implementation is suitable for local review. Publishing still requires final content/photo approval, a real domain and host, route metadata/prerendering, and the requested production QA pass.
